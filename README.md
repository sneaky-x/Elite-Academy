# ELITE Hotel Academy Website

A professional, modern, and fully responsive website for **ELITE Hotel Academy** – Sri Lanka's premier hospitality training institution.

## 🏨 About

Built with pure HTML, CSS, and JavaScript using Bootstrap 5. Designed for GitHub Pages hosting.

## 📁 Project Structure

```
EHAV2/
├── index.html          ← Main website file
├── css/
│   └── style.css       ← All custom styles
├── js/
│   └── main.js         ← Interactivity & animations
├── assets/
│   └── favicon.svg     ← Site icon
└── privateimages/      ← Academy photos (gallery)
```

## 🚀 Hosting on GitHub Pages

1. Create a new GitHub repository (e.g., `elite-hotel-academy`)
2. Upload all files maintaining the folder structure
3. Go to **Settings → Pages**
4. Set source to `main` branch, root folder
5. Your site will be live at `https://yourusername.github.io/elite-hotel-academy/`

## ✨ Features

- **Animated Preloader** with academy branding
- **Full-screen Hero** with auto-sliding background
- **Animated Counter Stats**
- **3 Program Cards** (Hotel Management, Housekeeping, Cleaning)
- **Filterable Photo Gallery** with lightbox viewer
- **Testimonials Slider** with touch/swipe support
- **Contact Section** with embedded Google Map
- **Mobile Responsive** — fully optimized for all screen sizes
- **Smooth Scroll & AOS Animations**
- **Back to Top Button**
